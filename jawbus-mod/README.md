# Jawbus Slots

Client-side Fabric mod for Minecraft 26.2. Shows a Lord Jawbus slot machine on your HUD.
Use `/jawbus` (or `/jawbus 5`) to test it.

## Build the jar

Needs JDK 25. Then run `./gradlew build` (Windows: `gradlew.bat build`).
The jar is `build/libs/jawbusslots-1.0.0.jar` (not the `-sources` one).
Put it in your `.minecraft/mods` folder next to Fabric API.
