# Jawbus Roll

Client-side Fabric mod for Minecraft 26.2. Plays a three-tier Iron Golem animation when a Lord Jawbus you killed drops a known reward.
Use `/jawbusRoll` for settings (it has preview buttons).

Build: needs JDK 25, run `./gradlew build`; the jar is `build/libs/jawbusslots-1.0.0.jar` (not `-sources`).
